# InterviewX ⚡

InterviewX is an AI-powered technical interview simulator. It parses your PDF resume, generates 10 tailored interview questions using Google's Gemini AI, and provides instant scoring and feedback for your answers.

## Features
* **Automated Resume Parsing:** Extracts skills and experience directly from your PDF using PyPDF2.
* **Dynamic Question Generation:** Uses Gemini AI to craft a mix of behavioral and technical questions specific to your background.
* **Real-time AI Evaluation:** Scores answers out of 10, highlighting strengths, areas for improvement, and providing a model answer hint.
* **Modern UI:** Glassmorphism design with a fully responsive frontend built in HTML/CSS/JS.

## Tech Stack
* **Backend:** Python, Flask, Flask-CORS
* **AI Integration:** Google GenAI SDK (Gemini 2.5 Flash)
* **File Parsing:** PyPDF2
* **Frontend:** Vanilla HTML, CSS, JavaScript
